# Module 09: Functions & Modules in Python

Welcome to **Module 09: Functions & Modules in Python**. This repository contains Python programs and examples to understand functions, arguments, return values, recursion, lambda functions, and modules.

## 📚 Topics Covered

1. Introduction to Functions
2. User-Defined Functions
3. Returning Values from Functions
4. Types of Arguments
5. Variable-Length Positional Arguments (`*args`)
6. Variable-Length Keyword Arguments (`**kwargs`)
7. Docstrings in Python Functions
8. Recursive Functions
9. Local and Global Variables
10. Functions as Arguments
11. Lambda Functions
12. `filter()` and `map()` with Lambda
13. Modules in Python
14. User-Defined Modules

## 🎯 Learning Objectives

* Understand how to define and call functions.
* Learn parameters, arguments, and return statements.
* Work with `*args` and `**kwargs`.
* Understand recursion and variable scope.
* Use lambda functions with `map()` and `filter()`.
* Learn how to import and create Python modules.
* Apply Python concepts in a simple banking application.
